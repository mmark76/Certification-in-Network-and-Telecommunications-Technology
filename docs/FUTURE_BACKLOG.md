# Future Backlog

Οι παρακάτω ιδέες δεν ανήκουν στην αρχική φάση. Αξιολογούνται αφού ολοκληρωθεί και επαληθευτεί ο βασικός εκπαιδευτικός κορμός.

## Περιεχόμενο

- πλήρης δίγλωσση ορολογία ελληνικά–αγγλικά,
- flashcards σε μορφή CSV/Anki,
- τυχαία διαγωνίσματα ανά θεματική,
- σενάρια προφορικής εξέτασης,
- mnemonic aids για πρωτόκολλα, θύρες και επίπεδα,
- διαγράμματα δικτύων και φύλλα εργασίας,
- ενότητα ιστορικών τεχνολογιών που παραμένουν στην εξεταστέα ύλη.

## Εργαλεία

- στατικός εκπαιδευτικός ιστότοπος,
- απλό quiz interface,
- αυτόματος έλεγχος εσωτερικών συνδέσμων,
- validation των IDs ερωτήσεων και εργαστηρίων,
- δημιουργία printable study sheets,
- GitHub Actions για markdown lint και link checking.

## Προχωρημένες δυνατότητες

- adaptive study plan βάσει λαθών,
- local-first progress tracking,
- δημιουργία mock exams από την τράπεζα ερωτήσεων,
- εργαστήρια με Packet Tracer ή άλλο επιτρεπτό simulator,
- προαιρετική χαρτογράφηση προς CCST/CCNA χωρίς ανάμειξη των syllabi.

## Κανόνας προτεραιότητας

Μία ιδέα μετακινείται στο ενεργό scope μόνο όταν:

1. ο βασικός χάρτης ύλης έχει επαληθευτεί,
2. υπάρχει σαφές μαθησιακό όφελος,
3. δεν αυξάνει δυσανάλογα την πολυπλοκότητα,
4. μπορεί να ελεγχθεί με αντικειμενικά κριτήρια.
