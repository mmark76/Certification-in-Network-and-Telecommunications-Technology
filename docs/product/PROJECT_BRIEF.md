# Project Brief

## 1. Όνομα έργου

**Network and Telecommunications Technology Study Tool**

## 2. Πρόβλημα

Το βοήθημα γνώσης καλύπτει διαφορετικά πεδία: υπολογιστές, λειτουργικά συστήματα, δίκτυα, τηλεπικοινωνίες, ασφάλεια και πρακτική διάγνωση. Η απλή ανάγνωση λυμένων απαντήσεων δεν εξασφαλίζει κατανόηση, ανάκληση ή πρακτική ικανότητα.

## 3. Λύση

Ένα ανοικτό, δομημένο εκπαιδευτικό repository που μετατρέπει το μοναδικό PDF γνώσης σε:

- μικρές μαθησιακές μονάδες,
- ερωτήσεις ενεργητικής ανάκλησης,
- σύντομα τεστ,
- πρακτικά εργαστήρια,
- επαναλήψεις βάσει αδυναμιών,
- δίγλωσση τεχνική ορολογία.

## 4. Κοινό

Κύριοι χρήστες:

- σπουδαστές και απόφοιτοι της ειδικότητας,
- εκπαιδευόμενοι που μελετούν το συγκεκριμένο βοήθημα,
- εκπαιδευτές που χρειάζονται οργανωμένο συμπληρωματικό υλικό,
- τεχνικοί που θέλουν επανάληψη βασικών γνώσεων.

## 5. Εκπαιδευτικοί στόχοι

Ο εκπαιδευόμενος να μπορεί:

1. να εξηγεί βασικές έννοιες με δικά του λόγια,
2. να αναγνωρίζει και να χρησιμοποιεί σωστά την τεχνική ορολογία,
3. να λύνει βασικούς υπολογισμούς δικτύων,
4. να εγκαθιστά και να ρυθμίζει απλά τοπικά δίκτυα,
5. να εκτελεί βασικό troubleshooting με συστηματική μεθοδολογία,
6. να απαντά ολοκληρωμένα σε θεωρητικές ερωτήσεις,
7. να επιδεικνύει τις απαιτούμενες πρακτικές δεξιότητες με ασφάλεια.

## 6. Τρέχον scope

Η πρώτη έκδοση περιλαμβάνει:

- χαρτογράφηση του PDF,
- κοινό πρότυπο για όλες τις εκπαιδευτικές ενότητες,
- θεωρητικές σημειώσεις,
- τράπεζα ερωτήσεων με IDs,
- πρακτικά εργαστήρια,
- πρόγραμμα και tracker μελέτης,
- αναφορές σε σελίδες ή ερωτήσεις της πηγής.

## 7. Εκτός scope πρώτης έκδοσης

- πλήρης web εφαρμογή,
- λογαριασμοί χρηστών και cloud συγχρονισμός,
- αυτόματη βαθμολόγηση με AI,
- mobile εφαρμογή,
- προετοιμασία για διαφορετικές πιστοποιήσεις όπως CCNA ή CompTIA,
- αναδημοσίευση ολόκληρου του προστατευόμενου βοηθήματος,
- προσθήκη δεύτερης πηγής γνώσης.

## 8. Κριτήρια επιτυχίας

Η πρώτη έκδοση θεωρείται επιτυχής όταν:

- το PDF έχει χαρτογραφηθεί χωρίς εμφανή κενά,
- κάθε βασικό θέμα έχει τουλάχιστον μία θεωρητική ενότητα,
- κάθε ενότητα έχει ερωτήσεις ανάκλησης,
- οι κρίσιμες πρακτικές δεξιότητες έχουν εργαστήριο,
- κάθε artifact έχει σαφή και ελέγξιμη αναφορά στο PDF,
- ο χρήστης μπορεί να ακολουθήσει τη διαδρομή χωρίς εξωτερική καθοδήγηση.

## 9. Βασική αρχή

> Κατανόηση πριν από απομνημόνευση, ανάκληση πριν από επανάληψη και πρακτική πριν από την αυτοπεποίθηση.
