## Στόχος

Να εκτελείς με ακρίβεια βασικές δυαδικές μετατροπές και να επαληθεύεις λογικές πράξεις χωρίς να βασίζεσαι αποκλειστικά σε υπολογιστή.

## Μαθησιακά αποτελέσματα

Με την ολοκλήρωση θα μπορείς:

- να μετατρέπεις αριθμούς από δεκαδικό σε δυαδικό και αντίστροφα,
- να μετατρέπεις δυαδικό σε δεκαεξαδικό,
- να συμπληρώνεις πίνακες αληθείας,
- να εντοπίζεις λάθη σε δοσμένες λύσεις,
- να εξηγείς τη μέθοδο με δικά σου λόγια.

## Εξοπλισμός

- χαρτί και μολύβι,
- προαιρετικά αριθμομηχανή μόνο για τελικό έλεγχο,
- προαιρετικά Python ή άλλο ασφαλές τοπικό εργαλείο επαλήθευσης.

## Ασφάλεια και περιορισμοί

Δεν υπάρχει τεχνικός κίνδυνος. Το εργαστήριο δεν απαιτεί πρόσβαση σε δίκτυο ή τρίτο σύστημα.

## Μέρος A — Πίνακες αληθείας

Χωρίς να κοιτάξεις τη θεωρία, συμπλήρωσε:

| A | B | AND | OR | XOR | NAND | NOR | XNOR |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 0 | 0 |  |  |  |  |  |  |
| 0 | 1 |  |  |  |  |  |  |
| 1 | 0 |  |  |  |  |  |  |
| 1 | 1 |  |  |  |  |  |  |

Στη συνέχεια εξήγησε προφορικά τη διαφορά OR και XOR.

## Μέρος B — Δυαδικό σε δεκαδικό

Μετέτρεψε και δείξε τα βάρη των θέσεων:

1. `1010₂`
2. `110101₂`
3. `10000000₂`
4. `11111111₂`
5. `10101100₂`

## Μέρος C — Δεκαδικό σε δυαδικό

Χρησιμοποίησε διαδοχικές διαιρέσεις με το 2:

1. `13₁₀`
2. `27₁₀`
3. `58₁₀`
4. `127₁₀`
5. `172₁₀`

Για κάθε αριθμό κράτησε πίνακα με διαίρεση, πηλίκο και υπόλοιπο.

## Μέρος D — Δυαδικό και δεκαεξαδικό

Μετέτρεψε:

1. `10101100₂` σε δεκαεξαδικό,
2. `11111111₂` σε δεκαεξαδικό,
3. `3A₁₆` σε δυαδικό,
4. `C0₁₆` σε δυαδικό,
5. `FF₁₆` σε δεκαδικό.

## Μέρος E — Εντοπισμός λάθους

Εξήγησε γιατί κάθε δήλωση είναι σωστή ή λανθασμένη:

1. `45₁₀ = 101011₂`
2. `1111₂ = E₁₆`
3. 8 bits μπορούν να δώσουν 255 διαφορετικούς συνδυασμούς.
4. Η XOR δίνει 1 όταν και οι δύο είσοδοι είναι 1.
5. Ο βασικός ASCII χρησιμοποιεί 8 bits και έχει 256 μοναδικούς κωδικούς.

## Έλεγχος με τοπικό εργαλείο

Μετά τη χειροκίνητη επίλυση, μπορείς να χρησιμοποιήσεις Python για επαλήθευση:

```python
values = [13, 27, 58, 127, 172]

for value in values:
    print(value, bin(value), hex(value))
```

Μην χρησιμοποιήσεις το εργαλείο πριν ολοκληρώσεις τις χειροκίνητες λύσεις.

## Έλεγχος επιτυχίας

Το εργαστήριο ολοκληρώνεται επιτυχώς όταν:

- έχεις τουλάχιστον 90% σωστές μετατροπές,
- συμπληρώνεις τον πίνακα αληθείας χωρίς βοήθεια,
- εξηγείς κάθε λάθος του Μέρους E,
- οι χειροκίνητες λύσεις συμφωνούν με τον τελικό έλεγχο.

## Troubleshooting

- **Αν η δυαδική τιμή είναι ανάποδη:** έλεγξε αν διάβασες τα υπόλοιπα από κάτω προς τα πάνω.
- **Αν η δεκαεξαδική μετατροπή είναι λάθος:** συμπλήρωσε μηδενικά αριστερά και ομαδοποίησε ανά 4 bits.
- **Αν μπερδεύεις OR και XOR:** θυμήσου ότι XOR σημαίνει «διαφορετικές είσοδοι» για δύο εισόδους.
- **Αν βρίσκεις 255 αντί 256 συνδυασμούς:** ξεχώρισε το πλήθος τιμών από τη μέγιστη αριθμητική τιμή.

## Ερωτήσεις αναστοχασμού

1. Ποιο βήμα σου προκαλεί τα περισσότερα λάθη;
2. Μπορείς να μετατρέψεις το `192₁₀` σε δυαδικό χωρίς διαδοχικές διαιρέσεις, χρησιμοποιώντας βάρη;
3. Πώς συνδέεται το `11111111₂` με ένα octet διεύθυνσης IPv4;
4. Γιατί το δεκαεξαδικό είναι πρακτικό στην πληροφορική και στα δίκτυα;
