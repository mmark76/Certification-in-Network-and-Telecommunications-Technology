# Πρακτικά εργαστήρια

Τα εργαστήρια μετατρέπουν τη θεωρία σε επαναλήψιμη τεχνική δεξιότητα. Μπορούν να εκτελούνται με πραγματικό εξοπλισμό ή, όπου επιτρέπεται, σε ασφαλές εικονικό περιβάλλον.

## Αρχικός κατάλογος

1. Αναγνώριση εξαρτημάτων υπολογιστή και δικτύου
2. Κατασκευή καλωδίου UTP με RJ45
3. Έλεγχος καλωδίου και διάγνωση λανθασμένου τερματισμού
4. Ρύθμιση στατικής IPv4 διεύθυνσης
5. Έλεγχος τοπικής και απομακρυσμένης συνδεσιμότητας
6. Βασικό subnetting και σχεδιασμός μικρού LAN
7. Ρύθμιση DHCP και DNS σε εργαστηριακό περιβάλλον
8. Βασική παραμετροποίηση switch
9. Δημιουργία VLANs και trunk link
10. Βασική παραμετροποίηση router και default route
11. Ρύθμιση και ασφάλιση ασύρματου δικτύου
12. Συστηματικό troubleshooting από το φυσικό επίπεδο προς την εφαρμογή

## Κανόνας πηγής

Κάθε εργαστήριο συνδέεται με συγκεκριμένο σημείο του μοναδικού PDF γνώσης. Δεν προστίθεται δεύτερη πηγή περιεχομένου.

## Κανόνας ασφάλειας

Οι ασκήσεις εκτελούνται μόνο σε ιδιόκτητο ή ρητά εξουσιοδοτημένο εξοπλισμό και δίκτυο. Δεν περιλαμβάνονται δοκιμές σε τρίτα συστήματα, παράκαμψη ελέγχων ή μη εξουσιοδοτημένη πρόσβαση.

## Κριτήριο κατοχής δεξιότητας

Μία δεξιότητα θεωρείται κατακτημένη όταν ο εκπαιδευόμενος μπορεί:

1. να εξηγήσει τον σκοπό της,
2. να την εκτελέσει χωρίς αντιγραφή βημάτων,
3. να αναγνωρίσει τουλάχιστον δύο συνήθη σφάλματα,
4. να επαληθεύσει αντικειμενικά το αποτέλεσμα,
5. να τεκμηριώσει τι έκανε.
