# Θεωρητικές ενότητες

Οι θεωρητικές ενότητες θα είναι σύντομες, αυτοτελείς και συνδεδεμένες με ερωτήσεις και πρακτικές ασκήσεις.

## Canonical σειρά

Το [`data/curriculum.yml`](../data/curriculum.yml) είναι η μοναδική πηγή
αλήθειας για τα 24 modules, τους κωδικούς εμφάνισης, τη σειρά τους, τους
θεματικούς τομείς και τα lesson paths. Νέα filenames
δεν δεσμεύονται σε αυτό το index πριν δημιουργηθεί και καταγραφεί το
αντίστοιχο εκπαιδευτικό περιεχόμενο στο canonical αρχείο.

Το [`data/theory-coverage.yml`](../data/theory-coverage.yml) είναι ο κανονικός
planning χάρτης για τις ταυτότητες ερωτήσεων και τα μελλοντικά κεφάλαια. Δεν
δηλώνει ότι υπάρχει αντίστοιχο theory file ή ολοκληρωμένο μάθημα.

Το `MOD-NN` είναι το μόνιμο τεχνικό ID ενός module και παραμένει στα paths,
registries, ownership relations και δεδομένα προόδου. Το `NN.NN` είναι ο
learner-facing κωδικός: το πρώτο ζεύγος προσδιορίζει το domain και το δεύτερο
τη θέση του module μέσα σε αυτό. Έτσι, `MOD-17` → `02.02` και `MOD-24` →
`09.04`.

Η ιεραρχία εμφάνισης ορίζεται από την εφαρμογή και είναι ανεξάρτητη από την
αρίθμηση ερωτήσεων του PDF. Τα σχεδιαζόμενα κεφάλαια έχουν κωδικό
`NN.NN.NN`, όπως `09.04.01`, και τεχνικό ID όπως `CH-09-04-01`. Προς το
παρόν υλοποιείται μόνο η ταξινομία και η ιχνηλασιμότητα, όχι το πλήρες
εκπαιδευτικό περιεχόμενο ή chapter pages.

## Definition of Done ενότητας

Μία ενότητα χαρακτηρίζεται `COMPLETE` όταν διαθέτει:

- [ ] 3–7 σαφείς μαθησιακούς στόχους
- [ ] ορισμούς των βασικών όρων
- [ ] πρωτότυπη αναλυτική εξήγηση
- [ ] τουλάχιστον ένα λυμένο παράδειγμα
- [ ] ενότητα «Συχνά λάθη»
- [ ] τουλάχιστον 10 ερωτήσεις ενεργητικής ανάκλησης
- [ ] σύντομο τεστ αυτοαξιολόγησης
- [ ] σύνδεση με πρακτική άσκηση, όπου εφαρμόζεται
- [ ] συγκεκριμένη αναφορά σε σελίδα, ερώτηση ή ενότητα του PDF
- [ ] ημερομηνία ελέγχου
- [ ] τεχνικό και γλωσσικό έλεγχο
