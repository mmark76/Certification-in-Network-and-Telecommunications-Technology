# Τράπεζα ερωτήσεων

Η τράπεζα ερωτήσεων χρησιμοποιείται για ενεργητική ανάκληση, προφορική εξάσκηση και γραπτή προσομοίωση εξέτασης.

## Σύστημα αναγνωριστικών

| Prefix | Κατηγορία |
|---|---|
| `GEN` | Γενικές γνώσεις πληροφορικής |
| `OS` | Λειτουργικά συστήματα |
| `NET` | Θεμελιώδεις αρχές δικτύων |
| `CAB` | Καλωδίωση και φυσικό επίπεδο |
| `IP` | IP addressing και subnetting |
| `SWR` | Switching και routing |
| `WLAN` | Ασύρματα δίκτυα |
| `TEL` | Τηλεπικοινωνίες |
| `SEC` | Ασφάλεια |
| `TRB` | Troubleshooting |

Παράδειγμα: `IP-001`.

## Διακριτά artifacts του MOD-01

- Το multiple-choice quiz χρησιμοποιεί τα IDs `GEN-001` έως `GEN-006` και
  εμφανίζεται στο [`practice-binary.html#quiz`](../practice-binary.html#quiz).
- Οι 12 flashcards χρησιμοποιούν τα IDs `GEN-101` έως `GEN-112`, καταγράφονται
  στο [`MOD-01-flashcards.md`](MOD-01-flashcards.md) και εμφανίζονται στο
  [`practice-binary.html#flashcards`](../practice-binary.html#flashcards).

Τα quiz questions και οι flashcards είναι διαφορετικοί τύποι artifact. Στο
`data/curriculum.yml` κάθε module έχει ξεχωριστές λίστες `questions` και
`flashcards`, καθώς και αντίστοιχα top-level registries. Κάθε flashcard
registry entry απαιτεί `id`, `module_id` και `html`, ενώ μπορεί να δηλώνει
προαιρετικά το Markdown αρχείο προέλευσης. Ο validator απαιτεί κάθε
καταχωρισμένο `data-flashcard-id` να εμφανίζεται ακριβώς μία φορά στο δηλωμένο
HTML και απορρίπτει ελλείπουσες ή ορφανές εγγραφές.

## Πρότυπο flashcard

```markdown
## IP-101 — Σύντομη ερώτηση ανάκλησης

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **Θέμα:** IP addressing
- **PDF reference:** σελίδα / αριθμός ερώτησης / ενότητα
- **Σημείωση:** `NEEDS_VERIFICATION`, όταν η αντιστοίχιση δεν είναι ακριβής

### Σύντομη απάντηση

Πρωτότυπη και σύντομη απάντηση.
```

Στο HTML η κάρτα χρησιμοποιεί το ίδιο ID σε `data-flashcard-id`, κρυφή
απάντηση, εμφανή δυσκολία/θέμα/παραπομπή και προσβάσιμα controls για εμφάνιση,
απόκρυψη και προσωπική αξιολόγηση.

## Κανόνες απαντήσεων

- Κάθε ερώτηση συνδέεται με συγκεκριμένο σημείο του μοναδικού PDF γνώσης.
- Κάθε αβέβαιη ή έμμεση αντιστοίχιση σημειώνεται `NEEDS_VERIFICATION` χωρίς
  επινόηση σελίδας ή ερώτησης.
- Η σύντομη απάντηση πρέπει να μπορεί να δοθεί προφορικά σε 30–90 δευτερόλεπτα.
- Η αναλυτική απάντηση εξηγεί το «γιατί» και όχι μόνο τον ορισμό.
- Οι αριθμητικές ασκήσεις δείχνουν όλα τα ουσιώδη βήματα.
- Οι εντολές συνοδεύονται από λειτουργικό σύστημα και αναμενόμενο αποτέλεσμα.
- Όπου το PDF παρουσιάζει ιστορική ή παρωχημένη πληροφορία, προστίθεται σημείωση πλαισίου χωρίς εισαγωγή δεύτερης πηγής.

## Μέθοδοι εξάσκησης

1. **Cold recall:** απάντηση χωρίς σημειώσεις.
2. **Teach-back:** εξήγηση σαν να διδάσκεται σε αρχάριο.
3. **Written exam:** πλήρης γραπτή απάντηση με χρονικό όριο.
4. **Error log:** καταγραφή λανθασμένων ή ατελών σημείων.
5. **Spaced review:** επανάληψη μετά από 1, 3, 7, 14 και 30 ημέρες.
