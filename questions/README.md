# Τράπεζα ερωτήσεων

Η τράπεζα ερωτήσεων χρησιμοποιείται για ενεργητική ανάκληση, προφορική εξάσκηση και γραπτή προσομοίωση εξέτασης.

## Σύστημα αναγνωριστικών

| Prefix | Κατηγορία |
|---|---|
| `GEN` | Γενικές γνώσεις πληροφορικής |
| `OS` | Λειτουργικά συστήματα |
| `NET` | Θεμελιώδεις αρχές δικτύων |
| `CAB` | Καλωδίωση και φυσικό επίπεδο |
| `IP` | IP addressing και subnetting |
| `SWR` | Switching και routing |
| `WLAN` | Ασύρματα δίκτυα |
| `TEL` | Τηλεπικοινωνίες |
| `SEC` | Ασφάλεια |
| `TRB` | Troubleshooting |

Παράδειγμα: `IP-001`.

## Κανόνες απαντήσεων

- Κάθε ερώτηση συνδέεται με συγκεκριμένο σημείο του μοναδικού PDF γνώσης.
- Η σύντομη απάντηση πρέπει να μπορεί να δοθεί προφορικά σε 30–90 δευτερόλεπτα.
- Η αναλυτική απάντηση εξηγεί το «γιατί» και όχι μόνο τον ορισμό.
- Οι αριθμητικές ασκήσεις δείχνουν όλα τα ουσιώδη βήματα.
- Οι εντολές συνοδεύονται από λειτουργικό σύστημα και αναμενόμενο αποτέλεσμα.
- Όπου το PDF παρουσιάζει ιστορική ή παρωχημένη πληροφορία, προστίθεται σημείωση πλαισίου χωρίς εισαγωγή δεύτερης πηγής.

## Μέθοδοι εξάσκησης

1. **Cold recall:** απάντηση χωρίς σημειώσεις.
2. **Teach-back:** εξήγηση σαν να διδάσκεται σε αρχάριο.
3. **Written exam:** πλήρης γραπτή απάντηση με χρονικό όριο.
4. **Error log:** καταγραφή λανθασμένων ή ατελών σημείων.
5. **Spaced review:** επανάληψη μετά από 1, 3, 7, 14 και 30 ημέρες.
