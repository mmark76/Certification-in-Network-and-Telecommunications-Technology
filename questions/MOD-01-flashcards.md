Οι απαντήσεις είναι πρωτότυπες, σύντομες διατυπώσεις για ενεργητική ανάκληση.
Οι αριθμητικοί υπολογισμοί έχουν επανεκτελεστεί αντί να αντιγραφούν μηχανικά.

## GEN-101 — Πότε η AND δίνει έξοδο 1;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 1, σελίδα PDF viewer 2

### Σύντομη απάντηση

Η AND δίνει 1 μόνο όταν όλες οι είσοδοι είναι 1.

### Βασικά σημεία βαθμολόγησης

- αναφορά σε όλες τις εισόδους,
- σαφής διάκριση από OR και XOR.

### Συχνή παγίδα

Να απαντηθεί «όταν τουλάχιστον μία είσοδος είναι 1», που περιγράφει την OR.

## GEN-102 — Ποια είναι η διαφορά OR και XOR;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 1, σελίδα PDF viewer 2

### Σύντομη απάντηση

Η OR δίνει 1 όταν υπάρχει τουλάχιστον μία είσοδος 1. Η XOR δίνει 1 όταν οι είσοδοι είναι διαφορετικές.

## GEN-103 — Τι κάνει η NOT;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 1, σελίδα PDF viewer 2

### Σύντομη απάντηση

Η NOT έχει μία είσοδο και αντιστρέφει τη λογική της τιμή: 0→1 και 1→0.

## GEN-104 — Πώς μετατρέπεται ένας θετικός δεκαδικός ακέραιος σε δυαδικό;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 5, σελίδες PDF viewer 3–4

### Σύντομη απάντηση

Διαιρούμε επανειλημμένα με το 2, κρατάμε τα υπόλοιπα και τα διαβάζουμε από το τελευταίο προς το πρώτο.

### Παράδειγμα ελέγχου

`5671₁₀ = 1011000100111₂`.

## GEN-105 — Πώς μετατρέπεται δυαδικός αριθμός σε δεκαδικό;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερώτηση 9, σελίδα PDF viewer 41

### Σύντομη απάντηση

Πολλαπλασιάζουμε κάθε bit με την αντίστοιχη δύναμη του 2 και προσθέτουμε τα αποτελέσματα.

### Παράδειγμα

`1010₂ = 1·2³ + 0·2² + 1·2¹ + 0·2⁰ = 10₁₀`.

## GEN-106 — Πώς γίνεται γρήγορα μετατροπή δυαδικού σε δεκαεξαδικό ή οκταδικό;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερωτήσεις 15–17, σελίδες PDF viewer 45–46

### Σύντομη απάντηση

Ομαδοποιούμε από δεξιά ανά 4 bits για δεκαεξαδικό ή ανά 3 bits για οκταδικό και μετατρέπουμε κάθε ομάδα ανεξάρτητα.

## GEN-107 — Τι είναι bit, byte και word;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερώτηση 38, σελίδες PDF viewer 60–61

### Σύντομη απάντηση

Bit είναι μία δυαδική κατάσταση. Byte είναι 8 bits. Word είναι ομάδα bits που εξαρτάται από την αρχιτεκτονική και δεν έχει σταθερό μέγεθος για όλους τους υπολογιστές.

## GEN-108 — Πόσες διαφορετικές τιμές αναπαριστούν n bits;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερώτηση 38, σελίδες PDF viewer 60–61

### Σύντομη απάντηση

`n` bits αναπαριστούν `2ⁿ` διαφορετικές τιμές. Για 8 bits υπάρχουν 256 συνδυασμοί, συνήθως 0–255 όταν είναι unsigned.

## GEN-109 — Τι είναι ASCII;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 7, σελίδα PDF viewer 4

### Σύντομη απάντηση

Το ASCII είναι σύστημα κωδικοποίησης χαρακτήρων που αντιστοιχίζει αριθμητικές τιμές σε λατινικούς χαρακτήρες, ψηφία, σημεία στίξης και χαρακτήρες ελέγχου.

## GEN-110 — Τι επιδιώκει το Unicode;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Α, ερώτηση 18, σελίδα PDF viewer 9

### Σύντομη απάντηση

Το Unicode επιδιώκει ενιαία αριθμητική αναπαράσταση χαρακτήρων από διαφορετικά συστήματα γραφής και τεχνικά σύμβολα.

## GEN-111 — Τι αλλάζει όταν ένα byte ερμηνεύεται ως unsigned ή ως two’s complement;

- **Δυσκολία:** Intermediate
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερώτηση 45, σελίδα PDF viewer 64
- **Σημείωση:** Η αριθμητική της απάντησης στο PDF παρουσιάζει ασυνέπειες· οι τιμές επανυπολογίζονται.

### Σύντομη απάντηση

Τα ίδια 8 bits διατηρούνται, αλλά αλλάζει η ερμηνεία. Unsigned: 0–255. Two’s complement: −128 έως 127, με το σημαντικότερο bit να συμμετέχει στην αρνητική στάθμιση.

### Έλεγχος υπολογισμών

- `AE₁₆ = 174` unsigned και `−82` σε signed 8-bit two’s complement.
- `83₁₆ = 131` unsigned και `−125` σε signed 8-bit two’s complement.

## GEN-112 — Γιατί είναι χρήσιμη η δεκαεξαδική γραφή;

- **Δυσκολία:** Basic
- **Τύπος:** Flashcard
- **PDF reference:** Ομάδα Β, ερωτήσεις 15–17 και 45, σελίδες PDF viewer 45–46 και 64

### Σύντομη απάντηση

Επειδή κάθε δεκαεξαδικό ψηφίο αντιστοιχεί ακριβώς σε 4 bits, άρα μεγάλες δυαδικές ακολουθίες γράφονται και ελέγχονται πιο εύκολα.
