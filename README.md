# EOPPEP Network and Telecommunications Technician Certification

Εκπαιδευτικό εργαλείο προετοιμασίας για την πιστοποίηση της ειδικότητας **«Τεχνικός Δικτύων και Τηλεπικοινωνιών»**.

> **English title:** Network and Telecommunications Technician  
> **Repository purpose:** Structured preparation for the EOPPEP certification examinations.

> **Pilot / Early Access — διαθέσιμη ύλη: 1 από 16 ενότητες.**
> Η επίσημη αντιστοίχιση της ύλης βρίσκεται σε εξέλιξη. Το έργο είναι ανεξάρτητο εκπαιδευτικό βοήθημα, δεν αποτελεί επίσημο υλικό του ΕΟΠΠΕΠ και δεν πρέπει ακόμη να χρησιμοποιείται ως μοναδικό βοήθημα πιστοποίησης.

## Ιστοσελίδα

Η διαδραστική εκπαιδευτική ιστοσελίδα είναι σχεδιασμένη για GitHub Pages:

**https://mmark76.github.io/Certification-in-Network-and-Telecommunications-Technology/**

Η πιλοτική έκδοση περιλαμβάνει αρχική σελίδα, canonical χάρτη 16 ενοτήτων, ένα διαθέσιμο μάθημα, ένα εργαστήριο, quiz και τοπική αποθήκευση προόδου.

Αν το GitHub Pages δεν έχει ενεργοποιηθεί ακόμη, επίλεξε στο repository:

`Settings → Pages → Build and deployment → Source: GitHub Actions`

## Σκοπός

Το repository οργανώνει τη μελέτη σε μικρές, ελέγξιμες ενότητες και συνδυάζει:

- θεωρία με απλή και ακριβή διατύπωση,
- ερωτήσεις ενεργητικής ανάκλησης,
- πρακτικά εργαστήρια,
- επαναλήψεις και αυτοαξιολόγηση,
- παρακολούθηση προόδου,
- ελληνική και αγγλική τεχνική ορολογία.

Δεν αποτελεί επίσημο υλικό του ΕΟΠΠΕΠ και δεν αντικαθιστά την εκάστοτε επίσημη εξεταστέα ύλη ή τις ανακοινώσεις του αρμόδιου φορέα. Μέχρι να ολοκληρωθεί και να τεκμηριωθεί η επίσημη αντιστοίχιση, πρέπει να χρησιμοποιείται μόνο συμπληρωματικά.

## Εκπαιδευτική μέθοδος

Κάθε ενότητα ακολουθεί τον κύκλο:

1. **Κατανόηση** — σύντομη θεωρία και βασικές έννοιες.
2. **Ανάκληση** — ερωτήσεις χωρίς άμεση προβολή της απάντησης.
3. **Εφαρμογή** — εργαστήριο, υπολογισμός ή ρύθμιση συσκευής.
4. **Έλεγχος** — μικρό τεστ και κριτήρια επιτυχίας.
5. **Επανάληψη** — προγραμματισμένη επανεξέταση των αδύναμων σημείων.

## Θεματικοί άξονες

- βασικές αρχές υπολογιστών και ψηφιακής λογικής,
- λειτουργικά συστήματα και τεχνική υποστήριξη,
- μοντέλα OSI και TCP/IP,
- Ethernet, καλωδίωση και δικτυακός εξοπλισμός,
- IPv4, IPv6 και subnetting,
- switching, routing και βασικές υπηρεσίες δικτύου,
- ασύρματα δίκτυα,
- τηλεπικοινωνιακά συστήματα,
- ασφάλεια δικτύων,
- διάγνωση και αποκατάσταση βλαβών.

## Γρήγορη εκκίνηση

1. Άνοιξε την εκπαιδευτική ιστοσελίδα ή το `index.html`.
2. Δες τον χάρτη στο `curriculum.html`.
3. Μελέτησε το πρώτο μάθημα στο `lesson-digital-logic.html`.
4. Ολοκλήρωσε το quiz και το εργαστήριο στο `practice-binary.html`.
5. Κατάγραψε αποτέλεσμα, λάθη και επόμενη επανάληψη.

## Κατάσταση έργου

**Pilot / Early Access — Σταθεροποίηση Φάσης 1**

- Διαθέσιμη ύλη: **1 από 16 canonical modules**.
- Κατάσταση `MOD-01`: **`NEEDS_VERIFICATION`**.
- Η επίσημη αντιστοίχιση με την ύλη του ΕΟΠΠΕΠ βρίσκεται σε εξέλιξη.
- Το [`data/curriculum.yml`](data/curriculum.yml) είναι η μοναδική πηγή αλήθειας για IDs, σειρά, τίτλους, διαθεσιμότητα και συνδέσεις artifacts.
- Η ανάπτυξη του Module 02 παραμένει μελλοντική εργασία και δεν περιλαμβάνεται στην παρούσα φάση σταθεροποίησης.
